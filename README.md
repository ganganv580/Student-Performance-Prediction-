# Student Performance Prediction Using Machine Learning

## 📌 Project Overview
This project focuses on predicting students' academic performance using Machine Learning techniques. It analyzes factors such as study hours, previous scores, sleep hours, extracurricular activities, and practice question papers to estimate student performance.

## 🎯 Objectives
- Analyze student academic performance.
- Identify factors influencing student performance.
- Perform data preprocessing and visualization.
- Build and train Machine Learning models.
- Compare model performance and predict student scores.

## 🛠️ Technologies Used
- Python
- Google Colab
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## 📊 Dataset Description
The project uses a simulated dataset containing 1,000 student records.

Features:
- Hours Studied
- Previous Scores
- Extracurricular Activities
- Sleep Hours
- Sample Question Papers Practiced

Target Variable:
- Performance Index

**Note:** The dataset is simulated for educational demonstration and is not real student survey data.

## 🤖 Machine Learning Algorithms
1. Linear Regression
2. Decision Tree Regressor
3. Random Forest Regressor

## ⚙️ Project Workflow
1. Dataset Generation
2. Data Preprocessing
3. Exploratory Data Analysis (EDA)
4. Train-Test Splitting
5. Model Training
6. Model Evaluation
7. Performance Prediction

## 📈 Evaluation Metrics
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

## 🔍 Results
The three machine learning models are compared using regression evaluation metrics. The best-performing model is selected based on its R² score.

## 🏁 Conclusion
This project demonstrates how Machine Learning regression algorithms can be applied to estimate student academic performance based on academic and lifestyle factors.
